## Citing XelToFab

If you use XelToFab in your research, please cite it using the following BibTeX entry:

```bibtex
@software{ma2026xeltofab,
  author       = {Ma, Zhao},
  title        = {{XelToFab}: Design Fields to Fabrication-Ready Geometry},
  year         = {2026},
  publisher    = {GitHub},
  url          = {https://github.com/xarthurx/XelToFab},
  version      = {0.3.4},
  license      = {MIT}
}
```
